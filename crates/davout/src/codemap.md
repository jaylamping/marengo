# crates/davout/src/

## Responsibility
`Supervisor<B: MotorBus>` implementation — operational state machine, command filtering, joint↔motor coordinate conversion, and feedback polling.

## Design
- `Supervisor` holds the `MotorBus`, limit policies, homing/enable state, per-address original pose timestamps, invalid-feedback gates, and private persistent fault authority.
- `reference.rs` owns private current-reference permission bound to the installed owner/backend realm and relevant effective motor/homing/control frame/envelope policy. History and pose are inspection/evidence, never permits. Relevant mutation, rebuild/patch, fault and stop uncertainty revoke permanently; ordinary successful Disable preserves reference and changes motion generation. `SelectionScope::Replace` (virtual: one joint replaces all) vs `Accumulate` (physical, ADR 0036: per-joint `ConsumedReferenceBinding`s with address, device epoch and MCU UID; `revoke_binding`/`revoke_joint` revoke one joint).
- `reference_physical.rs` (ADR 0036) — owner-local `PhysicalBackend` (realm, monotonic clock) and `PhysicalDevices`: per-address UID, coordinate epoch, continuity bounds (vendor MIT velocity range × dt + two quantization steps; at-rest tolerance across owner work), liveness against `comm_watchdog_ms` counted from a `SilenceFrom` the Supervisor picks (last frame; Active echo-pending: enable bounds start; Active target: earliest unanswered MIT/Enable write, none outstanding = no silence), with silence the host caused not counted (`count_silence_from`: an Enable echo, the stop ending an Active session; `owe_reporting_on`/`settle_owed_reporting_ons`: a type-24 On held out of a drive's possible post-SetZero blackout, `POST_SET_ZERO_BLACKOUT_FROM`..`POST_SET_ZERO_QUIET`, excuses the drive until written, at most `OWED_ON_WRITE_BOUND` (200 ms, pub) past the later of the quiet's end and owner work, then counts from the write; `Lapse::OwedOnUnwritten` otherwise), and watermarked identity/parameter-read inboxes so only replies popped after a request answer it. `IDENTITY_ADMISSION_TIMEOUT` (100 ms from the first request, pub) bounds the type-0 check at Enable; requests leave one `IDENTITY_ADMISSION_SPACING` (2 ms, pub) apart and a silent target is asked again every `IDENTITY_ADMISSION_RETRY` (10 ms, pub), since a drive drops type-0 during its 45-61 ms blackout 511-614 ms after SetZero. Both are exported for the measured-profile conformance test (`tests/firmware_profile.rs`).
- `burst.rs` — `BurstPacer` / `BURST_GROUP_SPACING` (2 ms, pub): one address group per spacing per interface for the reference baseline/finishing stops, the baseline's type-24 Offs, the status solicit and the enable bootstrap's MIT solicits (`write_mit_wires`: no frame to a target whose Enable is unwritten; a persistent session pacer, also fed by Enable waves and gate Offs, while a drive on the interface may still stream type-24), so replies cannot overrun the mcp251x's two receive buffers. Fault/E-stop/cancel/shutdown stops and post-bootstrap control output are never paced.
- `drive_loss.rs` (ADR 0038) — installed `DriveLossPlan`s, `shed_for_drive_loss` (one Disable per subtree address inside the detecting call), `DegradedEpisode` with Davout-owned deadline, shed-address frame inspection (Reset tolerated, other modes latch after `SHED_REPLY_GRACE`), every episode end latches `Communication`.
- `reference_transaction.rs` — bounded acquisition phases. Physical: BaselineStop (paced all-address stop; Off for applied streams except peers in their possible blackout, and the target) → DrainOld → RequestIdentity → AwaitIdentity → AwaitReportingOff (echoing bus: the target's Off echo read at least one control period ago, and `POST_SET_ZERO_QUIET` elapsed since the target's last SetZero) → ArmTarget → DrainPostArm → SetZero (recorded in `set_zero_on_wire`) → AwaitAck (type-2 after SetZero) → RequestReadback → AwaitReadback (type-17 0x7019) → all-address stop. `PHASE_TIMEOUT` 2 s per phase within `search_timeout_s`. `ReferenceStageStatus::CurrentEvidence` (renamed from `CurrentVirtualEvidence`).
- `reference_commit.rs` — durable journal commit and consumer; `CommitSelection::CurrentPhysical`; workflow API `request_reference(joint, sign_verified, ReferenceAudit)` → `ReferenceHandle`, `advance_reference_work()`, `reference_outcome(&handle)` → `ReferenceOutcome::{InProgress, Current{position_rad}, Failed{message}}`.
- `simulation.rs` owns a closed concrete in-memory transport, finite source-indexed raw/timed/envelope/typed/error scripts, declarative TX rules and attempted-delivery traces. `Supervisor<SimulationBus>::from_simulation` declares INITIAL virtual reference coverage through the shared initializer and normal safety logic. Generic constructors remain Unsupported; no arbitrary transport delegation, realm extraction, replacement or state conversion exists.
- `faults.rs` owns bounded fault records, separate complete/partial vendor domains and availability masks, first/latest receive envelope and incomplete-work evidence, observed warnings, stop attempts and the read-only `SafetySnapshot`. Records survive healthy poses, cache clearing, replay and disable. No qualified recovery/reset is available.
- `ControlMode` enum mirrors proto wire type (gravity, impedance, position, torque).
- `JointCommand` / `MitJointCommand` / `SpeedCommand` — command DTOs before/after filtering.
- `DavoutError` — typed invalid requests/runtime failures, persistent `FaultLatched`, and truthful aggregate `StopDelivery` errors.
- `validate_control_candidate` — read-only combined policy validation for control overlays before live/durable installation.
- `from_repo` shares one initializer with the closed simulation constructors. Ordinary construction resolves runtime configuration; simulation takes the supplied root's `config/` directly (ADR0031). Legacy calibration history is never read and no history path is accepted: every startup is Unhomed, and only a qualified reference workflow grants current reference. The reserved history location (`homing.yaml calibration_record_path`, never read) must stay distinct from the reference journal. Mutable registry/unchecked Ready/synthetic pose/generic mutable bus APIs are removed. Plain constructors have no reference backend and refuse with `ReferenceUnsupported` (ADRs 0022/0023).
- `from_repo_with_physical_reference(root, bus, journal)` (ADR 0036) install the physical backend, absolute distinct journal and `CurrentPhysical` selection. `calibrate_joint_zero` drives that workflow to a terminal outcome (2 ms poll, `search_timeout_s` + 10 s, `disable_all` on timeout). `verify_physical_identities` re-reads type-0 for every Enable target before any Enable frame; `reference_binding_valid` revokes per joint on epoch/UID/liveness change.

## Flow
Enable path: normal/scoped/Active-shortcut private reference gate → complete bounded drain of old queued status → preflight/drive enable → complete final nonblocking drain and repeated authority gate → new receive session → `OperationalMode::Active`. Saturated preflush refuses activation; saturated/malformed final flush rolls back through all-address stop.
Shutdown: `disable_all` → all-address zero-speed / neutral-MIT / ordinary-disable attempts → `Disabled` + `StopReport`; failed writes remain uncertainty, not physical acknowledgement.
Per-tick: `admit_and_send_mit` → whole-batch checks/filters → checked joint→motor conversion → every-active-address pose watchdog (a pose is stale once a write it answers is unanswered for `comm_watchdog_ms`; the host's own silence does not age it) → `bus.mit_control_all_at` → each address's write instant noted as an unanswered solicit until a pose is admitted

Only neutral MIT status solicitation is allowed before initial pose, bounded by the communication deadline. Invalid admission emits no frame and restores output history. Expired watchdog, device/feedback hazards and transport uncertainty latch and automatically stop; rejected operator requests stay nonlatching. `check_fault_authority` is the owner mode-entry gate, and `stop_generation` invalidates old controller intent.

Feedback: observe current reference binding (policy, realm, model, identity, epoch; liveness only for echo-pending Active targets) → bounded `recv_feedback_report` → merge motor/Error/first backend failure by raw delivery ordinal → installed address/type/transform lookup → inspect every fault/mode/hard-position/malformed event → choose latest admissible pose per address → once-per-drain derivative policy → latch incomplete completion independently → judge grant liveness → first-hazard best-effort stop. Active reference mismatch still consumes all evidence and stops the original installed routes once; policy restoration cannot revive permission. A timestamp tie cannot hide or reorder a raw hazard; host dequeue times do not justify differentiating every queued pose. Malformed and Remote events never renew pose; partial payloads never become complete fault words, and Error frames remain transport evidence. Idle/Quiet is observed host quiescence, with 64 raw frames/256 attempts per poll; it is not an atomic physical snapshot or a Pi jitter qualification.
