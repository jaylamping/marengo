# PROTOTYPE — Hardware page UI

**Throwaway.** Not production. Answers: *What should the Consul Hardware page feel like?*

Three variants on `/prototype/hardware?variant=A|B|C`, switchable via the floating bar.

| Key | Name | Structure |
|-----|------|-----------|
| A | Stage | Full-bleed interactive 3D humanoid; click joint → settings sheet |
| B | Limb rail | Horizontal limb strips + focus stage; sheet from selection |
| C | Ortho board | Flat schematic / exploded board of clickable joints (no orbit hero) |

Run: `cd consul && npm run dev:prototype-hardware`
