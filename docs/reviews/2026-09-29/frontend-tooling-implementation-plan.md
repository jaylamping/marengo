# Consul and tooling implementation plan

This plan covers every **F01–F25 and T01–T32** finding in the [finding index](finding-index.md), including already repaired and partially repaired rows. It complements the control/gateway work and the [test-quality plan](test-quality-plan.md). Baseline is maintenance main `52f12678277a2cae786d8df648f035895789f026`; the original source evidence stays in [Consul](consul.md) and [tooling](tooling.md).

The largest rewrite should replace execution ownership, not replace the entire UI. One long-lived Pi process owns motors. Consul, MCP and CLI become typed clients of that process. A Pi MotionSession owns run admission, owner/lease, target/mode/gains, boot identity, generation, cancellation and terminal outcome. A Pi configuration authority owns validated live/durable generations and import/activation transactions. The gateway forwards commands and correlated outcomes; browser timers cannot become motor policy.

Preserve Berthier→Davout→robstride and joint-space ownership. Preserve hardware commissioning gates, including the currently false Wave sign-off. Windows sources and local CAD stay under `J:\code\marengo`; Mac uses a native checkout of the same repository. Linux is the container/robot target, not another authoritative WSL development tree.

Write ADRs for MotionSession, ConfigAuthority and immutable install/state separation before architectural implementation. Introduce a narrow API with fake-clock/bus/filesystem adapters, then migrate one client at a time behind the same admission checks. Remove legacy mutating routes only after all clients use that API. Avoid a simultaneous whole-repo rewrite that makes source/behavior regressions hard to locate.

## Delivery sequence and stop conditions

1. **Test evidence and contained repairs:** land public analytic dynamics tests plus real discovered algorithm repair, stop/fault/cap regressions, script syntax/quoting/results fixes and cold-cache research tests. Keep files small and independent. These packages can begin before a new frontend architecture exists.
2. **Safety and authoritative freshness:** land P0 and P3 contracts first. Consul must render Unknown honestly and reject stale-state actions while the motion migration is underway. All legacy mutations receive the same authentication/admission policy.
3. **MotionSession vertical slice:** start with explicit Enable, one manual Hold, Cancel and correlated status across Pi→gateway→Consul/MCP/CLI. Prove late-command barrier before migrating Wave/compound/teach. Replace timers only as each runtime capability exists; retain a deterministic preview path.
4. **ConfigAuthority vertical slice:** Set Limits generation/receipt, then Set Zero reference epoch, then model stage/resolve/activate and deployment reservation. Transfer MCP sync and installer preservation into that same authority; remove competing file writers.
5. **Tooling/install ownership and history:** immutable source/release/state separation; fail-closed process outcomes; bounded local mirror; archive paging/search and actual job target receipts. Finish native Mac/Windows smoke after portable transport seams are available.
6. **Models and retirement:** semantic CAD/URDF/MJCF equivalence, actual controller simulation, remove unmounted legacy UI/scaffold success paths and redundant style/source-string tests after replacement evidence. Final backlog review distinguishes software fixed from physical acceptance pending.

Each PR should list finding IDs, changed contract, prior counterexample, targeted red→green test, targeted mutation evidence where justified, full relevant gate and remaining limits. Rerun only affected tests while iterating; run required CI gates before merge. Do not merge a broad refactor if the old unsafe behavior remains green by construction.

Software closure requires the specific counterexample to fail safely and its acceptance contract to pass through the real responsible module. A reported queue/write/process start is not completion. Hardware torque readback, reference verification after power/assembly changes, supported-arm stop mechanics, CAD measurement fidelity, and outstanding bench ladder/Wave sign-off require an explicit operator session. They remain visible tasks after software work; this plan does not enable motion, deploy to Pi, or close the five retained hardware/product issues by assertion.
