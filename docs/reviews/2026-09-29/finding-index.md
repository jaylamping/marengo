## Current runtime and intended contracts

The reviewed runtime is a five-DOF right bench arm. Berthier produces joint commands, Davout filters/enables them, and Robstride owns CAN encoding/I/O. Root YAML and the master URDF seed startup; live limits are authoritative while the Pi runs and write behind to disk. General URDF Accept resolves supported joint fields, archives and promotes the merged master on disk, then requires Pi restart. It does not hot-reload arbitrary geometry/dynamics into the running model.

Several desired contracts remain unimplemented or incomplete: current-boot reference proof, latched fault recovery, a trustworthy stop outcome, drive-local timeout/torque handshake, full live/durable configuration generations, acknowledged motion ownership/cancellation, and hardware E-stop/Hall integration. The detailed reports distinguish those architecture decisions from defects in code that already claims to implement a behavior. The historical commissioning record still has incomplete elevated gravity/50% ladder/Wave acceptance; no present robot state was inspected.
