## Dispositions

| Disposition | Rule used here |
|---|---|
| **PRUNE** | Card confidence high, or medium/mechanical where the card shows zero references and the item is not safety, fault, stop or watchdog code. No decision needed. |
| **PRUNE-AFTER** | Depends on another prune item, a fix, a test rewrite, a doc/ADR edit, a proto deprecate-then-reserve step, or a stated verification (named in **Depends on**). |
| **DECIDE** | Needs a user decision (table below). |
| **KEEP** | The evidence says it is still needed, or the card recommends keeping it. |

Safety, fault, stop and watchdog code is never PRUNE for being untested. Where a card lists stop-adjacent or cap code as prunable (`stop_speed_command`, the danger-zone branch, the gravity preflight, the tau_ff_max derivation), it is PRUNE-AFTER with the safe replacement or equivalence test named. Coverage gaps on safety code are leads (`leads-index.md`), not prune evidence. Proto deletions need a deprecate-then-reserve step or a `buf breaking` exception (contracts.md P26).
