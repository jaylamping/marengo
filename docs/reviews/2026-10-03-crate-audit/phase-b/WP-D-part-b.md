## loop.rs touch points (for merge)

All call-site only:

- `use crate::gain_runtime::{…}`: adds `GainShapeError`.
- `LoopError`: new variant `GainShape(#[from] GainShapeError)` after `InvalidLoopPeriod`.
- `ControlLoop` constructor: `gains: GainRuntime::for_loop_hz(loop_hz)` (was `GainRuntime::new()`).
- `set_control_mode_inner`: `wire_gains_now(..)` now returns a `Result`; `.unwrap_or_else(|error| { tracing::error!(..); Vec::new() })`.
- `tick`: `LoopError::GainShape(_)` added to the discard-intent `matches!` list.
- `tick_inner`: both `resolve_all(..)` calls gain a trailing `?`.
